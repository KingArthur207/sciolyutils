porta

Porta from the Division B and C rules: decrypt a letter when you are told the key. The key letter picks a row (A and B share one, C and D the next, and so on) and along that row A–M swap with N–Z. Key E, cipher R: R is 4 into N–Z, row E,F is 2, 4 − 2 = 2, which is C. Porta is its own inverse, so the same table encrypts and decrypts.

Key

A keyword like LEMON runs along ten letters, the way it does on a real message, so you also practise keeping your place in the key.

Learning the math

Numbers shows which half the letter is in and how far in (R = N+4), plus which row the key picks. Show the math writes the equation with a ?: add the row if the letter is in A–M and count the answer in N–Z, subtract it if the letter is in N–Z and count in A–M. Work your way to no help.

The math

  • The key letter picks a row: A,B is row 0, C,D row 1 … Y,Z row 12. So E is row 2.
  • Letter in A–M? Count its position (A = 0), add the row, count that far into N–Z. C 2 + row 2 = 4, four into N–Z is R.
  • Letter in N–Z? Count its position (N = 0), subtract the row, count that far into A–M. Under 0, add 13.

The table way

  • Find the row whose pair contains your key letter.
  • If your letter is in the top line A–M, read straight down into that row.
  • If it is in the row, read straight up to the top. Either way you land on the answer.
